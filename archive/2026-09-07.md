## 7. macOS Agent Skill Automates Native Apps Without APIs — 6.0/10

The Swift-based huashu-mac-use project gives coding agents a reusable skill for controlling macOS applications that lack APIs. It emphasizes background state inspection, non-disruptive writes, and reproducible evidence, making desktop automation more auditable than one-off UI scripting.

**Source**: OSS / GitHub  
**Original**: https://github.com/alchaincyf/huashu-mac-use

## 8. pd-bridge Splits LLM Prefill and Decode Across CUDA and Metal — 6.0/10

pd-bridge demonstrates heterogeneous inference for DeepSeek-V4-Flash: vLLM performs prefill on an NVIDIA DGX Spark, oMLX performs decode on a Mac Studio, and the state crosses ordinary 10GbE. The small project illustrates a practical prefill-decode split across CUDA and Apple Metal hardware without specialized networking.

**Source**: OSS / GitHub  
**Original**: https://github.com/chadhurley25075-png/pd-bridge
